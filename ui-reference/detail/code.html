制作步骤

1

鸡腿去骨，洗净后用厨房纸吸干水分，两面划几刀，方便入味。

2

放入照烧酱、生抽、料酒、蜂蜜、蒜末，抓匀腌制15分钟以上。

3

热锅倒油，放入鸡腿皮面朝下煎至金黄，翻面煎2分钟。

4

倒入剩余酱汁，小火焖煮5分钟，收汁至浓稠即可。
