# 金小明的食谱

微信小程序原生项目，首页 UI 根据 `ui-reference` 中的 `screen.png`、`code.html` 和 `DESIGN.md` 还原。

## 打开方式

1. 使用微信开发者工具打开当前目录。
2. AppID 可选择测试号，项目内默认使用 `touristappid`。
3. 编译后默认进入 `pages/index/index` 首页。

## 页面

- `pages/index/index`：首页
- `pages/category/index`：分类界面，对应 `ui-reference/category`
- `pages/lottery/index`：抽奖界面/今天吃啥，对应 `ui-reference/lottery`
- `pages/detail/index`：菜谱详情界面，对应 `ui-reference/detail`
- `pages/publish/index`：发布食谱界面，对应 `ui-reference/publish`
- `pages/favorite/index`：收藏界面，对应 `ui-reference/favorite`
- `pages/mine/index`：我的界面，对应 `ui-reference/mine`
